## 0. 共用設定(看懂以下數字的前提)

- **策略主體**:H雙引擎 B純切 = 權重 `(多頭H 1.0, 多頭reb 0, 空頭H 0, 空頭reb 1.5)`。
  - 「多空」用 **0050 收盤 vs MA20** 判:站上→打 H 動能分;跌破→打反彈分。
  - H 分數 `h_score = (0.35趨勢+0.35相對強度+0.15量+0.10RSI+0.05均線)×100×(0.8+0.4×成交值百分位)`。
  - 反彈分 = `rebound_signal` 的 score×100(×1.5 是空頭權重)。
- **執行引擎 ⑤** = `sim_buyclose_sellopen`(exp_60d_entry_compare.py):A@收盤買、B①@隔日開盤賣(exit_only)、B②@開盤補買(可關)。
  - **exit_only**:只賣「掉出名單」的,不修剪贏家 → 讓贏家跑。
  - **incumbent ×1.5**:排名時持股分數 ×1.5(黏著、抗 churn);配重/曝險用原始分數。
- **universe**:`data/base_universe.json`(112 檔,正式)。擴充版 v2/v3/v4 是 gitignored 的實驗檔(可用 build_universe_tech.py 重生)。
- **資金**:DCA 15000 + 每交易日 1000、上限 5 萬。
- **成本**:買 0.1425% / 賣 0.4425% / 滑價 0.1% / 漲停買不到。**還原價**(get_daily_ohlcv,除息還原)。
- **ALPHA = 策略報酬 − 同資金 DCA 進 0050**(剝大盤 beta)。
- **時間軸**:6 個 END 往回窗口(60/90/126/252/378/504日)+ 5 個真實 regime(2021復甦/2022空頭/2023復甦/2024-25多頭/2025下-26)。

### 🔴 三個一定要記住的方法學 caveat
1. **絕對 alpha 偏高、被灌水**:exit_only 不修剪 + 回測**沒套用實盤的單股上限**,贏家能無限長大 → 絕對數字膨脹。**只看「相對排名/方向」,別把 +200% 當真實報酬。**
2. **資料只有日線**:沒有分鐘/逐筆 → 任何「盤中擇時」都無法回測。
3. **current-universe-on-history**:universe 用現在的清單套歷史,本身有輕微存活/選股偏誤(尤其手動挑「已知會漲」的族群時,見 v19)。

## 1. 逐一實驗

### v10 — 整合回測 + universe look-ahead 修正  `scripts/exp_step1_v10.py`
- **目的**:把 v6(6窗口)+ regime 合一,比 112檔 vs「成交值前20檔」。
- **方法**:16 變體(A~L+組合+反彈)+ H雙引擎A/B/C,跑 11 欄。前20檔分「現在快照」與「point-in-time(各欄起始日往前60日成交值)」兩版。
- **結果**:
  - 112檔最佳 = **H雙引擎C(最差欄 −10、平均 +91)**。
  - 「**現在快照前20**」報酬爆高(B 2年 +317 alpha)= **look-ahead 偏誤**(用2026後見之明挑2021贏家)。
  - 改 **point-in-time 前20** 後崩到 B 2年 −7、平均 +29 → **證實偏誤;且修正後 20檔全面輸 112檔**。
- **結論(成功)**:① 集中前20沒比較好(去偏誤後);② 共同罩門是 **2024-25多頭**(集中選股打不過大盤普漲)。
- **可驗證**:重跑比對 point-in-time vs 快照前20 的差距。
- **可改進**:point-in-time universe 重建頻率?用市值而非成交值分層?

### v11 — 0050 趨勢判斷 × 回看天數  `scripts/exp_step1_v11.py`
- **目的**:固定 H雙A/B/C,換不同 0050 多空判斷規則,能否變好。
- **方法**:6 種判斷(c>MA20 / c>MA60 / c>MA120 / MA20>MA60 / 季+排列 / ret60>0)× A/B/C。
- **結果**:慢判斷(MA60、MA20>MA60)**把 2022空頭由負轉正(−5→+15~+23)、平均更高**,但**代價是 2024-25多頭更差**(−28→−50~−72)。最差欄基準 c>MA20 + H雙C 仍最小(−7)。
- **結論(取捨,非單贏)**:要平均→慢判斷;要最差欄最小→原版 c>MA20。實盤維持 MA20。
- **可改進**:不對稱遲滯偵測(`c>MA20且MA20>MA60`才轉多、`c<MA60`才轉空)——**沒測過**,值得試。

### v12 — 每季獨立報告 × 三架構  `scripts/exp_step1_v12.py`
- **目的**:每季期初5萬獨立,比 V1單一策略 / V2每日0050切策略 / V3每季切。
- **結果(重要)**:全期複合 **V1 H雙引擎C +703% >> V2每日切 +429% >> V3每季切 +319%**(0050 基準 +225%)。
- **結論(成功,關鍵)**:**「內部軟混分」海放「頂層硬切策略」**;切得越粗(季)越差。原因:硬切丟掉另一引擎的個股機會。
- **可驗證**:重跑看 V1>V2>V3 是否穩。
- **可改進**:V2 的切換訊號用別的(非 MA20)?但 v11/v15 已暗示頂層切換路線不優。

### v13 — 開盤腿執行法  `scripts/exp_step1_v13.py`
- **目的**:收盤買後,開盤「只賣」vs「視情況買賣」(多組開盤補買條件)。
- **結果**:**開盤只賣(現行實盤)平均最高**;開盤補買大多拉低;只有「開低才補」勉強接近。
- **結論(成功)**:維持開盤只賣;開盤無腦補買=追高傷。
- **可改進**:「開低才補」在實盤值不值得做(回測微正)?

### v14 — incumbent 持股加權 × 反彈權重  `scripts/exp_step1_v14.py`
- **目的**:掃 incumbent ∈ {1.0,1.2,1.5,2.0,3.0};掃雙引擎權重。
- **結果(重要)**:
  - **INC=1.0(=當時實盤漏了incumbent)= 全場最爛**(平均+18/最差−81/換手325x)。
  - **INC=1.5 平均最高 +225**;**INC=2.0 最穩**(最差−5、每regime正、換手117x)。換手隨 INC 單調下降。
  - 權重:B純切/多頭混反彈(1,0.3,0,1.5)報酬最高;H雙C最抗跌。
- **結論(成功,促成修正)**:**incumbent 是必加**(實盤已補回,預設1.5)。
- **可改進**:INC 隨 regime 動態(空頭調高更黏)?

### v15 — incumbent 統一 vs 不對稱  `scripts/exp_step1_v15.py`
- **目的**:測「賣用×1.5、買新用原始分」的不對稱方案(直覺上更合理)。
- **結果(失敗)**:不對稱**全面更差**(換手暴增270x、平均+44、最差−76)。
- **結論(失敗,已否決)**:×1.5 的本質是**換股遲滯**(新股要比持股強1.5倍才換);拿掉買方遲滯→追新股稀釋贏家→churn爆。**維持統一×1.5**。

### v16/v17 — 族群動能因子(112檔)  `exp_step1_v16.py` / `v17.py`
- **目的**:加「族群動能」乘數(同類股一起漲就加分)。v16 原始動能;v17 超額動能(−大盤)。
- **結果(混合→邊際)**:v16 60日強版微贏 plain 但傷近期短窗;v17 超額版 +242 微贏 plain +225,**但增量很小**,因 112 缺薄族群(被動元件只國巨1檔)。
- **結論**:邊際、不乾淨。
- **重要**:**乘數用「百分位」是個瑕疵**(見 v21)。

### exp_group_factor_diag / analyze / validate(族群因子診斷三件套)
- `exp_group_factor_diag.py`:族群動能**有預測力且獨立於RS**(超額60日 IC +0.12、控制RS後偏相關 +0.12)→ **訊號是真的**。
- `exp_group_analyze.py`:**原始相關分群被大盤beta汙染**(族群動能與大盤相關 0.64;台達電被42檔當鄰居=市場blob)。只有緊密族群(金融/航運/記憶體)分得乾淨。
- `exp_group_validate.py`:**超額動能正確把被動元件排第1**(20日+99%、60日+279%);**記憶體沒上榜**(只有DRAM漲、群聯/旺宏跌=非整族群)→「整族群動才算」的廣度需求成立。

### v18 — 族群因子 × 擴充259檔  `scripts/exp_step1_v18.py`

### v19 — 小幅擴充118檔(112+被動元件4+矽智財2)  `scripts/exp_step1_v19.py`

### v20 — 各產業前N名 universe 174檔  `scripts/exp_step1_v20.py`
- **目的**:治本——每產業收流動性前15名(不靠事後挑)。
- **結果(報酬高但回撤爆)**:plain H **+232平均(最高)/ 最差−59(最爛)**(2024-25 melt-up 集中高beta科技重傷)。族群因子仍更差。
- **結論**:不划算(+7報酬換−33回撤惡化)。

### v21 — 修正族群因子(幅度乘數+掃相關窗)  `scripts/exp_step1_v21.py`
- **目的**:修 v16-20 的兩個瑕疵——① 百分位壓平(極端訊號被壓成跟勉強正一樣)② 相關窗固定120。
- **方法**:乘數改 `clip(1+超額動能×0.6, 0.7, 1.4)`(近0→1.0自動關、極端才放大);掃相關窗 60/90/120/150/180/250。
- **結果(關鍵教訓)**:幅度乘數+**窗120**衝到 +240(贏 plain),**但掃細才發現 120 是孤立尖峰**(90→168、120→240、150→141)= **過擬合**;沒有穩定窗能贏 plain。
- **結論(失敗,已否決族群因子)**:訊號真但**換成可交易 edge 後只剩過擬合**。
- **方法學亮點**:**掃尺度是抓過擬合的關鍵**(單一參數突出、鄰居崩 = 不可信)。

### v22 — 日線 MACD 死叉出場  `scripts/exp_step1_v22.py`
- **結果(失敗)**:平均 +225→+115(當日)/+194(連2日),**最差季沒變好**。動能股回檔假死叉→太早賣掉贏家。
- **結論(失敗)**:**別加 MACD 出場;盤中版會更糟**(更洗+無法回測)。

### exp_overnight_study — 隔夜 vs 日間報酬(學術②)  `scripts/exp_overnight_study.py`
- **結果(成功,⑤ 的學術根基)**:
  - **隔夜(昨收→今開)+0.268%/日(年化≈+67%);日間(今開→今收)−0.153%/日(≈−39%)** → 報酬幾乎全在隔夜、日間是負的。
  - 各規模(大/中/小型)隔夜溢價都在(+0.25~0.28%),**非僅中小型**。
  - **鎖漲停隔日:隔夜跳空 +2.28%(正常10倍)後日間反轉 −0.23%** = 「開高出貨」。
- **結論**:⑤(買收盤賣開盤)是這異象最佳解;**強力反對盤中持有/擇時**(日間是負的)。

### exp_overnight_gradient — 今日強度→隔夜溢價梯度  `scripts/exp_overnight_gradient.py`
- **結果(失敗,別加傾斜)**:隔夜溢價對「今日漲跌幅」**非單調(U型)**;**「7~9.4%強但買得到」桶 +0.230% 低於平均**;只有鎖漲停(+2.26%,買不到)突出;大跌日隔夜也高(超跌反彈)。
- **結論**:**沒有可加的「今日強度」買腿傾斜**;雙引擎(動能+反彈)剛好覆蓋兩端。

### exp_rebound_audit — 反彈引擎行為稽核  `scripts/exp_rebound_audit.py`
- **結果(成功,健康)**:反彈觸發稀有(全期2631次/~1.8%);174個反彈進場部位,**85%抱住≥3日**(平均8.2日)、平均 +2.0%總報酬(~+0.24%/日≈被動隔夜)。對照 H 進場 +5.7%/12日。
- **結論**:反彈引擎沒壞、抱得住、有小賺,但**是防禦配角**(扣費後剩不多)。

## 2. 貫穿性結論(最重要)

1. **策略的 edge = 讓贏家跑**:隔夜溢價 + exit_only 不修剪 + incumbent黏著 + ⑤買收盤賣開盤。
2. **幾乎每個「聰明 overlay」都傷它**:頂層切策略(v12)、不對稱incumbent(v15)、族群因子(v16-21)、MACD出場(v22)、今日強度傾斜(gradient)——**全部失敗,因為它們提早打斷贏家**。
3. **universe 越大不一定越好**(v18 +147檔傷基準;v20 治本版報酬高但回撤爆;112 是最佳平衡)。
4. **定案**:**112檔 + H雙引擎B純切 + incumbent×1.5 + ⑤,開盤只賣**。這是反覆驗證下最穩的。
5. **唯一未解的真問題**:2024-25 多頭那種大盤寬幅普漲時,集中選股打不過 0050——這是結構性的,不是參數能解。
