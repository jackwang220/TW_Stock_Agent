## 0. 最重要的三件事(real money)

1. **這是真錢交易**。任何動到 `scripts/live_dual_v5_trade.py` 或下單邏輯的改動,務必先 dry-run、先跟使用者確認。
2. **賣腿是 exit_only**(只賣「掉出名單」的,不會減碼還在名單的持倉)。這個機制決定了很多設計,別假設能無痛調曝險(見 §3 下檔保險)。
3. **回測 headline 會灌水約一倍**。已用 walk-forward 量化:實單合理期望 ≈ 回測數字的一半(見 §4)。別拿回測的 +200%/+1500% 去期待實單。

## 1. Live 策略精確設定(已驗證,2026-06-18)

主程式:`scripts/live_dual_v5_trade.py`。選股核心 = **H雙引擎 B純切**,與回測引擎(exp_step1_v9 的「原版c>20MA」)**完全一致**。

| 項目 | 設定 |
|---|---|
| 選股 | weights `(1,0,0,1.5)` = B純切:多頭純 H 動能、空頭純反彈(rebound×1.5) |
| regime | `0050 收盤 > MA20` → 多頭打 H;跌破 → 空頭打反彈 |
| incumbent | `INC = 1.75`(持股分數×1.75 黏著;今天從 1.5 改;穩健中間值) |
| 執行 | ⑤:收盤前買(吃隔夜溢價)、隔日開盤賣;**exit_only**(低換手) |
| 資金 | DCA 期初15000/日+1000/上限50000;單股持有上限 `MAX_POSITION_TWD`=20000 |
| **下檔保險** | **A2:`0050 收盤 < MA60` → 當天完全空手**(`PROTECT_MA=60, PROTECT_SCALE=0.0`) |
| 持股數 | top-3(第4名≥90%才進) |

**下單腿(launchd 排程,台北時間)**:
- 09:02 賣腿(`--leg sell`):掉出名單的出場 + 若防禦日(<MA60)名單空 → 全出清成現金
- 13:05 買腿(`--leg buy`):名單內買到目標(漲停買不到會跳過/備選)

**目前是訊號/手動模式**(股票在元大,Shioaji 只連永豐):排程帶 `--ledger` 不送單,只推 Discord 訊號,使用者在元大手動下單後用 `ledger.py` 記帳。要真正 API 下單才拿掉 `--ledger`、走 `--sim`→`--live`(見 `docs/live_trading_runbook.md`)。

## 2. 今天(2026-06-18)改了什麼

1. **`INC` 1.5 → 1.75**(`live_dual_v5_trade.py` 頂部)。原因:滾動窗驗證 1.5/1.75/2.0 接近,1.75 是「哪種行情都不太差、不在刀尖」的穩健中間值。
2. **新增下檔保險 A2**:`0050<MA60 → 當天完全空手`。新增常數 `PROTECT_MA/PROTECT_SCALE`、`compute_picks` 回傳 `defensive` 旗標、防禦日把 `sel` 清空(走既有 exit_only 全出清,零新風險邏輯)。
3. `exp_60d_entry_compare.py` 的 `sim_buyclose_sellopen` 回傳多加 `day_pnl/cal/contributed`(供研究 overlay 用,不改既有邏輯/數字)。

**為什麼是 A2(全空手)不是半倉**:使用者本來想要「半倉」,但**半倉在 exit_only 下要新增『賣腿 trim 到目標』的邏輯,而回測是用 P&L overlay 理想化過、未經實單驗證**。A2(全空手)是唯一「忠實驗證 + 純 exit_only 零新邏輯」的,所以 go-live 用 A2 最安全。半倉(`PROTECT_SCALE=0.5` + 已寫好但未驗的 trim 邏輯)留作日後驗證後再開。

## 3. 下檔保險的來龍去脈(別誤用)

策略本質 = **多頭爆衝放大器**:大盤噴它噴更兇,但**下跌時跌更多**(2025-04 急跌 0050 −25、策略 −41)、安靜盤小賠。所以加「下降趨勢就不玩」的擇時開關。

驗證結論(`scripts/protect_test.py` / `protect_validate.py` / `exposure_test.py` / `slide_test.py`):
- **A2(<MA60 全空手)= 最佳且唯一忠實**:2022 空頭 −58→−24、2025-04 −36→0,總報酬與多頭爆衝幾乎全留。是「保險」(多頭年付小保費),不是免費 alpha;**不會降低「多頭中回檔」的單一最大回撤**。
- **半倉/連續調曝險/滑動倉位/反波動 全都更差或不忠實**(反波動還會砍掉高波動的爆衝窗;滑動在陰跌比不防禦還慘)。**鐵律:簡單決斷 > 花俏 curve-fit。**
- MA40~120 都有幫(plateau、非 curve-fit),MA60 最佳。

## 5. 重要規矩(使用者偏好)

- **別一直問、自己判斷往前**;只有不可逆/對外動作(push、真實下單、刪檔)才先停。
- **別擅自縮小範圍**(112 檔別偷縮)。
- **2020 前資料不重要**(別推薦 2008/2015/2018;空頭只用 2020+:COVID 2020Q1、2022)。
- **任何新訊號/參數一律 walk-forward**(只用過去資料選、滾動 OOS 評估),別再全史搜最佳→overfit。
- **比較策略前先曝險中性化**(高曝險在多頭虛假贏)。
- **價格務必用還原價**(yfinance auto_adjust 或專案 `get_daily_ohlcv` 的 `_sanitize`;raw FinMind 未還原會錯)。
