# 操作說明(白話版)— v5 訊號自動化

> 你的角色:**看 Discord 訊號 → 在元大手動下單 → 記一筆帳**。機器人只算訊號+推播,**不會幫你下單**(你的股票在元大,Shioaji 只連永豐、碰不到元大)。

---

## 1. 每天會自動發生什麼(你不用做事)

排程(launchd)每個交易日自動跑兩次,推到你的 Discord:

| 時間 | 你會收到 | 你要做的事 |
|---|---|---|
| **09:02 開盤後** | 🔴 **賣出訊號**(要賣哪幾檔) | 到元大手動賣 → 記帳 |
| **13:05 收盤前** | 🟢 **買進訊號**(要買哪幾檔、約多少錢) | 到元大手動買 → 記帳 |

> 週末/國定假日會自動跳過,不會亂推。

---

## 2. 每天標準流程(照做就好)

**早上(收到賣出訊號後):**
1. 看 Discord 那則「賣出腿」,上面寫要賣什麼。
2. 到元大 App 手動賣(可不賣,自己決定,但策略建議照做)。
3. 賣完記帳(把實際成交價填進去):
   ```bash
   uv run python scripts/ledger.py sell 2409 86 23.5
   #                                    代號 股數 成交價
   ```

**下午(收到買進訊號後):**
1. 看 Discord 那則「買進腿」,上面寫要買什麼、約多少錢。
2. 到元大 App 手動買。
3. 買完記帳:
   ```bash
   uv run python scripts/ledger.py buy 2327 4 868
   #                                   代號 股數 成交價
   ```

**隨時想看現在持有/損益:**
```bash
uv run python scripts/ledger.py show
```

> 記帳很重要:機器人靠這本帳才知道你手上有什麼,隔天才算得出「該補買/該賣」。

## 3. 想自己手動跑一次看訊號(不必等排程)

**注意:要在盤中(09:00–13:30)跑才有即時價。**

```bash
# 看今天「要買什麼」
uv run python scripts/live_dual_v5_trade.py --leg buy --live-signal --ledger

# 看今天「要賣什麼」
uv run python scripts/live_dual_v5_trade.py --leg sell --ledger
```

跑完一樣會推一則到 Discord,終端機也會印出來。**這只是看訊號,不會下單。**

## 4. 💰 我有閒錢想多投進去,怎麼讓它跑?

機器人有個「**可投資金(現金池)**」數字,用來算每檔要買多少。預設是 **DCA 自動長大**:
- 起始 **15,000**,每個交易日 **+1,000**,長到 **50,000 封頂**。

要它動用更多錢,**最簡單就是設「現金池」**(設一次,之後所有執行+排程都用這個金額):

### ⭐ 推薦做法:設現金池(一行指令,排程也跟著變)
```bash
uv run python scripts/ledger.py cash 30000   # 把可投資金池設成 30,000
uv run python scripts/ledger.py cash          # 查目前設定
uv run python scripts/ledger.py cash auto     # 取消,恢復 DCA 自動
```
設了之後,**早上/下午的自動排程、和你手動跑,通通用這個金額**。想加錢就把數字調大,想縮小就調小,想回到自動就 `cash auto`。

### 做法 B:只想這一次用更多錢(一次性,不影響排程)
手動跑買腿時加 `--capital 金額`:
```bash
uv run python scripts/live_dual_v5_trade.py --leg buy --live-signal --ledger --capital 35000
```

> **資金優先序**:`--capital`(一次性) > 現金池(`cash`) > DCA 自動。
> 觀念:這個數字 ≈ 你想投入的總金額(持股市值 + 現金)。它越大,每檔買的目標金額越大。

## 5. 想暫停 / 緊急停止

```bash
# 暫停(之後任何自動/手動執行都會拒跑)
touch /Users/test/Documents/Code/TW_Stock_Agent/KILL_SWITCH

# 恢復
rm /Users/test/Documents/Code/TW_Stock_Agent/KILL_SWITCH
```

完全關掉自動排程:
```bash
launchctl bootout gui/$(id -u)/com.twstock.v5.buy

# 要再開:launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.twstock.v5.buy.plist(sell 同理)
```

## 6. 常見問題

**Q：沒收到 Discord 推播?**
- 先確認那時間是不是交易日、Mac 有沒有開著沒睡。
- 看當天紀錄:`reports/live/<日期>_buy.log`(或 _sell.log)。

**Q：機器一定要開著嗎?**
- 對。**09:02 和 13:05 時 Mac 要開機、已登入、有網路**。系統已設不睡;但**MacBook 別闔蓋**(會強制睡)、別關機。

**Q：訊號叫我賣掉我才剛買的股票?**
- 正常。策略只抱「當下最強的前幾名」,掉出名單就賣。要不要照做你自己決定(都是手動)。

**Q：有些股它說買不到 / 跳過?**
- 接近漲停(買不到)、或單價太高小資金買不起 1 股(例如川湖一股 7,000 多),都會自動跳過,正常。

## 7. 重要提醒

- **它只給訊號,不會自動下單**;所有買賣都你在元大手動執行。
- **策略**:H雙引擎 B純切(多頭買強勢股、空頭轉防禦);最差的季度可能回撤約 −18%,這是策略本質、不是壞掉。
- **加錢/改參數後**,建議先手動跑一次(第 3 節)確認訊號金額是你要的規模,再交給排程。
- 詳細技術/維運(排程安裝、憑證、上線下單)看 [`docs/live_trading_runbook.md`](live_trading_runbook.md)。
